# semestralniprace
Movie generator button - Rozdělené na filmy a seriály potom rozdělené podle žánrů, pokud se mu to bude líbit ukáže se mu nějaká ikonická scéna.
1 stránka bude rozdělená na 2 button "seriál" nebo "film"
potom by se to hodilo na stránku se žánry kde by byly taky najaký buttons "Horor", "sci-fi", "action", "Romantika" , "OG", "Thriller"
A z toho by to vyplivlo nejaký ten film nebo seriál, bylo by tam napsané nějaké info a ikonická scéna pokud by se mu to nelíbilo vygeneruje mu to něco jiného
